# 25. Repository Transactionnel

L'idée est d'avoir des méthodes de repository capable d'être utilisées en mode transactionnel dans des services métier.



## Exemple de Repository

```cs
public class DelegueRepository(IDapperContext context)
{
    private readonly IDapperContext _context = context;
    
    // Divers méthodes
    
    public async Task<int> Update(
        int id, 
        DelegueDto data, 
        int demandeAvisId, 
        int uid, 
        IDbConnection? connection = null, 
        IDbTransaction? transaction = null
    )
    {
        var sql = """
                  update Delegue set
                      Nom               = @Nom
                      ,Prenom            = @Prenom
                      ,Email             = @Email
                      ,Fixe              = @Fixe
                      ,Gsm               = @Gsm
                      ,ModificationLe    = GetDate()
                      ,ModificationPar   = @uid
                  where Id = @id
                      and DemandeAvisId = @demandeAvisId
                  """;
        
        var sqlParams = new DynamicParameters(data);
        sqlParams.AddDynamicParams(new { id, demandeAvisId, uid });

        // Si on passe la connection, on utilise celle-là
        if (connection is not null)
        {
            return await connection.ExecuteAsync(sql, sqlParams, transaction);
        }

         // Sinon on créé une connection
        using var localConnection = _context.CreateConnection();

        return await localConnection.ExecuteAsync(sql, sqlParams);
    }
```

Il y a **deux** modifications par rapport à la méthode classique :
```cs
// Premièrement
public async Task<int> Update(
        ... , 
        IDbConnection? connection = null, 
        IDbTransaction? transaction = null
    )
```

On met `null` comme valeur par défaut pour pouvoir utiliser la méthode dans un mode non transactionnel :
```cs
await repo.UpdateWithTransaction(id, data, demandeAvisId, uid);
```

Sans devoir ajouter `null`.

```cs
// Deuxièmement
if (connection is not null)
{
    return await connection.ExecuteAsync(sql, sqlParams, transaction);
}
```



## Utilisation dans un service

```cs
public class MonTraitementMetierService(IDapperContext context, DelegueRepository repo)
{
    public async Task MontraitementComplexTransactionnel(int id, DelegueDto data, int demandeAvisId, int uid)
    {
        using var connection = context.CreateConnection();
        
        using var transaction = connection.BeginTransaction();
        
        connection.Open();
		try
        {
            await repo.Update(id, data, demandeAvisId, uid, connection, transaction);
            await repo.Update(id, data, demandeAvisId, uid, connection, transaction);
            await repo.Update(id, data, demandeAvisId, uid, connection, transaction);
            await repo.Update(id, data, demandeAvisId, uid, connection, transaction);

            transaction.Commit(); 
        }
        catch
        {
            transaction.Rollback()
        }
    }
```

Et dans un `endpoint` sans transaction :

```cs
public async Task EndpointStyle(int id, DelegueDto data, int demandeAvisId, int uid)
{
    await repo.UpdateWithTransaction(id, data, demandeAvisId, uid);
}
```

```cs
using Microsoft.Data.SqlClient;

public abstract class RepositoryBase
{
    private readonly SqlConnectionFactory _connectionFactory;

    protected RepositoryBase(SqlConnectionFactory connectionFactory)
    {
        _connectionFactory = connectionFactory;
    }

    protected async Task<T> WithConnectionAsync<T>(
        Func<SqlConnection, SqlTransaction?, Task<T>> action,
        SqlExecutionContext? context,
        CancellationToken ct)
    {
        if (context is not null)
        {
            return await action(context.Connection, context.Transaction);
        }

        await using var connection = await _connectionFactory.CreateOpenConnectionAsync(ct);
        return await action(connection, null);
    }

    protected async Task WithConnectionAsync(
        Func<SqlConnection, SqlTransaction?, Task> action,
        SqlExecutionContext? context,
        CancellationToken ct)
    {
        if (context is not null)
        {
            await action(context.Connection, context.Transaction);
            return;
        }

        await using var connection = await _connectionFactory.CreateOpenConnectionAsync(ct);
        await action(connection, null);
    }
}
```

    public Task AddAsync(Customer customer, CancellationToken ct, SqlExecutionContext? context = null)
